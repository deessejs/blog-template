# When to Add a Feature

Before shipping anything new, ask three questions:

## Who asks for it?

A real user, an internal stakeholder, or your own itch? The first two carry more weight than they should; the third carries less.

## What does it cost to remove?

If "impossible" is the answer, that's a red flag. The best features are easy to delete a year later.

## What does it block?

New work that this feature would unblock is usually worth more than the feature itself.
